# ChangelogAll notable changes to **userbase-backend** are documented here.Versioned notes live under **`changelogs/`**:- [v0.0.0 — 2026-03-20](./changelogs/v0.0.0.md) — Initial API, auth (JWT + refresh), `verifyJwt`, OpenAPI/Scalar, security baseline.- [v0.1.0 — 2026-03-24](./changelogs/v0.1.0.md) — **User/role/status model** (`User` + `AdminUser`), **admin-only user APIs** (list/filter/search, update, deactivate), notifications, validation, tests, doc/error alignment (same JWT/RBAC pattern as v0.0.0; **403** message text standardized).- [v0.1.1 — 2026-03-24](./changelogs/v0.1.1.md) — Reminders moved into a **separate `reminders` collection** with `/api/reminders` list + mark-read APIs; `POST /api/notifications/:notificationId/remind` now stores/returns a reminder; OpenAPI/README/tests synced.The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
