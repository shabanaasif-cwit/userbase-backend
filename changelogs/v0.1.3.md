# v0.1.2 - 2026-03-27

(D) 2026-03-27

### Added

- Persist `firstName`/`lastName` on `User` and `AdminUser` records.

### Changed

- Signup now requires at least one of `firstName` or `lastName`, and each provided name must start with a capital letter.
- Signup password length is now enforced between 8 and 64 characters.
- Email validation for signup and login now requires a valid top-level domain (e.g. `.com`, `.net`).
- Login auto-appends `@suybmol.com` when a user omits `@` in the email field.
- Email local-part (before `@`) is limited to 20 characters for signup and login.
