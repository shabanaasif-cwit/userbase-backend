### Changed

- `POST /api/auth/signup` now validates passwords on the server before creating an account: `password` must match `confirmPassword`, must not contain whitespace or backticks, must be between 8 and 64 characters, and must include at least one digit and one special character (non-alphanumeric). Errors use the same messages as the existing password policy elsewhere in the API.

### Fixed

- Signup returns **409** with `Email already registered` when the email already exists in **either** the regular user collection or the admin collection, so the same address cannot be registered twice across roles.
