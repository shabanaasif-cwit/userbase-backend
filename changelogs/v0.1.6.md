# v0.1.6 — 2026-07-13

(D) 2026-07-13

### Added

- Admin signup can now be protected with an environment-based `ADMIN_SIGNUP_KEY`.
- Documentation now explains the new admin signup requirement and payload field.

### Changed

- Signup flow now requires an `adminKey` when creating an admin account.

### Fixed

- Admin signup now rejects requests that do not include the configured `adminKey`.

### Security (if applicable)

- Added admin signup protection to reduce unauthorized admin account creation.

### Internal

- HTTP integration tests updated to cover admin signup key enforcement.
