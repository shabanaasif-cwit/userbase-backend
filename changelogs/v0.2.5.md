### Changed

- **Auth (`authService`)**: Signup and duplicate-email paths now return the message `That email is taken. Try another.` instead of `Email already registered`.
- **Admin users (`userAdminService`)**: Admin-driven email updates use the same duplicate-email message as signup.
- **Login (`authService`)**: Loads `User` and `AdminUser` in parallel with `Promise.all`, then selects the matching account; validates password and account state as before.

### Fixed

- **Login (`authService`)**: Returns `401` with `Could not find the user with this role.` when credentials match an account whose stored role does not match the `role` sent on login, so clients cannot treat a successful password check as success for the wrong role.

### Security (if applicable)

- **Login**: Tightens role handling by requiring the resolved account's `role` to match the requested login role after authentication checks.
