# userbase-backend

Node.js + Express API for the userbase project.

## Setup

```bash
npm install
```

Copy `.env.example` to `.env` and adjust `PORT` if needed.

## Run

```bash
npm run dev   # dev with auto-reload (Node --watch)
npm start     # production-style run
```

## Endpoints

- `GET /` — API info
- `GET /health` — health check
